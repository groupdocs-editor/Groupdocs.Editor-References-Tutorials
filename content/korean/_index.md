# GroupDocs.Editor API – .NET 및 Java용 문서 편집

포괄적인 **GroupDocs.Editor API** 문서 및 튜토리얼 허브에 오신 것을 환영합니다! 숙련된 개발자이든 이제 시작하는 개발자이든, 이 중앙 리소스는 .NET 및 Java 애플리케이션에 고품질 문서 편집, 변환 및 처리를 통합하는 데 필요한 모든 것을 제공합니다. GroupDocs.Editor API를 사용하면 Microsoft Office 또는 Adobe Acrobat 없이 문서를 로드, 편집 및 저장할 수 있어 클라우드 우선 및 온프레미스 솔루션에 이상적입니다.

## 빠른 답변
- **GroupDocs.Editor API는 무엇을 하나요?** 문서를 로드하고 편집 가능한 HTML로 변환하며, 콘텐츠를 수정할 수 있게 하고 레이아웃을 유지하면서 원본 형식으로 다시 저장합니다.  
- **지원되는 플랫폼은 무엇인가요?** Windows, Linux, macOS에서 .NET 6+ 및 Java 8+를 모두 지원합니다.  
- **Office를 설치해야 하나요?** 외부 Office 또는 Acrobat 설치가 필요하지 않습니다.  
- **지원되는 파일 형식은 몇 개인가요?** DOCX, XLSX, PPTX, PDF, HTML, XML, TXT, CSV 등을 포함하여 40개 이상의 입력 및 출력 형식을 지원합니다.  
- **API가 안전한가요?** 예 – 기본적으로 비밀번호 보호, 암호화 및 세밀한 권한 관리를 제공합니다.

## GroupDocs.Editor API란 무엇인가요?
**GroupDocs.Editor API**는 개발자가 Microsoft Office 또는 Adobe Acrobat 없이도 다양한 파일 유형을 프로그래밍 방식으로 로드, 수정 및 저장할 수 있게 해주는 문서 편집 API입니다. 문서 변환을 처리하고 레이아웃을 유지하며, 양식 필드와 암호화와 같은 고급 기능을 단일하고 일관된 객체 모델을 통해 지원합니다.

## 왜 GroupDocs.Editor API를 선택해야 하나요?
GroupDocs.Editor는 표준 서버 하드웨어에서 500페이지 문서를 5초 미만으로 처리하며, **40개 이상의** 파일 형식을 지원합니다—클래식 Office 파일, PDF, XML, 일반 텍스트 및 구분 형식 등을 포함합니다. 이 API는 비용이 많이 드는 타사 소프트웨어의 필요성을 없애고, 내장 보안(비밀번호 보호, 암호화 및 권한 제어)을 제공하며, Windows, Linux, macOS 전반에 걸쳐 일관되게 작동해 모든 사용자에게 신뢰할 수 있는 편집 경험을 제공할 수 있습니다.

## 누가 혜택을 받을 수 있나요?
GroupDocs.Editor API는 CMS 개발자, 배치 문서 생성을 필요로 하는 자동화 엔지니어, 보안 서버 측 처리가 필요한 기업 팀, 협업 편집을 제공하는 SaaS 제공업체, 그리고 PDF, 스프레드시트, 프레젠테이션을 실시간으로 생성·수정하는 보고 솔루션에 유용합니다.

## 자주 묻는 질문
**Q: 지원되는 문서 형식은 무엇인가요?**  
A: GroupDocs.Editor는 DOCX, DOC, XLSX, XLS, PPTX, PPT, PDF, HTML, XML, RTF, ODT, ODS, ODP, TXT, CSV 등을 포함한 40개 이상의 형식을 지원합니다.

**Q: Microsoft Office를 설치해야 하나요?**  
A: 아니요, GroupDocs.Editor는 Microsoft Office나 기타 외부 애플리케이션 없이 독립적으로 작동합니다.

**Q: 웹 애플리케이션에 GroupDocs.Editor를 구현할 수 있나요?**  
A: 물론입니다! GroupDocs.Editor는 웹 애플리케이션에 최적이며, 브라우저 기반 문서 편집 솔루션을 구축할 수 있습니다.

**Q: GroupDocs.Editor는 안전한가요?**  
A: 예, API는 비밀번호 보호, 암호화 및 권한 관리를 포함하여 문서를 안전하게 보호합니다.
