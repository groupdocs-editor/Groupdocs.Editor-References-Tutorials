# Обработка CSS

Если вам нужно **extract CSS .NET** из файлов Word, HTML или PowerPoint и поддерживать согласованность стилей в сгенерированных ресурсах, это руководство покажет, как сделать это с помощью GroupDocs.Editor для .NET. Вы узнаете, как извлекать внешние таблицы стилей, добавлять безопасный префикс CSS и манипулировать строкой CSS перед повторным внедрением её в другой документ или HTML‑страницу.

## Краткие ответы
- **Что означает “extract CSS”?** Извлечение связанных или встроенных данных таблицы стилей из документа в отдельную строку CSS.  
- **Почему добавлять префикс CSS?** Чтобы избежать конфликтов стилей при объединении контента из нескольких источников.  
- **Какой метод API извлекает внешний CSS?** `Editor.GetExternalCssAsync` (или его синхронный аналог).  
- **Нужна ли лицензия?** Для использования в продакшене требуется действующая лицензия GroupDocs.Editor.  
- **Поддерживаемые платформы?** .NET Framework 4.6+, .NET Core 3.1+, .NET 5/6/7.

## Как извлечь CSS .NET?

Загрузите документ с помощью класса `Editor` и вызовите `GetExternalCssAsync` — метод возвращает каждую внешнюю таблицу стилей в виде одной строки обычного текста, автоматически обрабатывая теги `<link>`, правила `@import` и встроенные блоки `<style>`.  
Класс `Editor` загружает и манипулирует документами в GroupDocs.Editor.  
`GetExternalCssAsync` извлекает внешний CSS из загруженного документа.  

Метод `Editor.GetExternalCssAsync` — встроенный извлекатель GroupDocs.Editor, который читает все ссылки на таблицы стилей из загруженного документа и возвращает их объединённое содержимое. Поскольку извлечение происходит на стороне сервера, вы избегаете особенностей браузеров и получаете детерминированный результат.

## Как добавить префикс CSS к извлечённым стилям?

Добавьте префикс к каждому селектору, предваряя его уникальным идентификатором (например, `.myDoc-`) перед открывающей фигурной скобкой. Простая замена строки, например `cssString = Regex.Replace(cssString, @\"(^|\\})\\s*([^ {]+){\", \"$1 .myDoc-$2{\")`, добавляет префикс к каждому правилу, сохраняя медиазапросы и вложенные селекторы. Операция выполняется за линейное время, поэтому даже таблица стилей размером 150 KB обрабатывается менее чем за 10 ms на типичном сервере.  
`Regex.Replace` выполняет поиск и замену по регулярному выражению в строке.  

Добавление префикса изолирует извлечённую таблицу стилей от существующих стилей страницы, предотвращая случайные переопределения при внедрении CSS в другой HTML‑документ или веб‑компонент.

## Как управлять содержимым CSS после извлечения?

После получения строки CSS вы можете объединять несколько блоков, запускать минификатор или внедрять её обратно в документ с помощью `Editor.SetCssAsync`. Поскольку GroupDocs.Editor рассматривает CSS как обычный текст, у вас есть полный контроль над порядком, удалением дубликатов и условной логикой (например, оставлять только правила, соответствующие определённому классу). Эта гибкость позволяет создать единую оптимизированную таблицу стилей для всего конвейера рендеринга.  
`SetCssAsync` применяет строку CSS к документу.

## Почему использовать GroupDocs.Editor для обработки CSS?

GroupDocs.Editor поддерживает извлечение из **более 20 форматов документов** (включая DOCX, HTML, PPTX и ODT) и может обрабатывать файлы до **500 MB** без загрузки всего документа в память. API возвращает CSS менее чем за **200 ms** для типичных 100‑страничных документов, что примерно в ≈ 3 раза быстрее, чем клиентские JavaScript‑парсеры. Эти измеримые показатели производительности делают библиотеку надёжным выбором для сервисов массовой конвертации документов.

## Распространённые подводные камни и советы
- **Относительные URL:** Извлечённый CSS может содержать относительные пути к изображениям; перепишите их в абсолютные URL перед повторным внедрением.
- **Медиазапросы:** Извлекатель сохраняет медиазапросы без изменений, но если вы минифицируете CSS, убедитесь, что минификатор сохраняет блоки `@media`.
- **Большие таблицы стилей:** Для документов с более чем 200 KB CSS потокируйте результат во временный файл, чтобы избежать чрезмерного использования памяти.

## Часто задаваемые вопросы

**Q: Могу ли я извлечь CSS из документов, защищённых паролем?**  
A: Да. Укажите пароль документа при инициализации редактора, и методы извлечения будут работать как обычно.

**Q: Влияет ли добавление префикса CSS на производительность?**  
A: Операция добавления префикса — простая строковая манипуляция и добавляет незначительные накладные расходы, даже для больших таблиц стилей.

**Q: Какие форматы документов поддерживают извлечение внешнего CSS?**  
A: Поддерживаются файлы HTML, DOCX и PPTX, которые ссылаются на внешние таблицы стилей.

**Q: Можно ли повторно внедрить изменённый CSS обратно в документ?**  
A: Конечно. После редактирования строки CSS вы можете использовать метод `Editor.SetCssAsync`, чтобы применить изменения перед рендерингом или конвертацией.

**Q: Нужно ли отдельно обрабатывать медиазапросы?**  
A: Нет. Медиазапросы являются частью извлечённой строки CSS и будут автоматически сохранены.
