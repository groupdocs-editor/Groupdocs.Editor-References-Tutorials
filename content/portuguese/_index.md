# GroupDocs.Editor API – Edição de documentos para .NET e Java

Welcome to the comprehensive **GroupDocs.Editor API** documentation and tutorials hub! Whether you're a seasoned developer or just getting started, this central resource gives you everything you need to integrate high‑fidelity document editing, conversion, and processing into your .NET and Java applications. The GroupDocs.Editor API lets you load, edit, and save documents without Microsoft Office or Adobe Acrobat, making it ideal for cloud‑first and on‑premise solutions.

## Respostas rápidas
- **O que a GroupDocs.Editor API faz?** Ela carrega documentos, converte‑os em HTML editável, permite modificar o conteúdo e salva de volta ao formato original preservando o layout.  
- **Quais plataformas são suportadas?** Windows, Linux e macOS para .NET 6+ e Java 8+.  
- **Preciso ter o Office instalado?** Não são necessárias instalações externas do Office ou Acrobat.  
- **Quantos formatos de arquivo são suportados?** Mais de 40 formatos de entrada e saída, incluindo DOCX, XLSX, PPTX, PDF, HTML, XML, TXT e CSV.  
- **A API é segura?** Sim – oferece proteção por senha, criptografia e gerenciamento granular de permissões pronto para uso.

## O que é a GroupDocs.Editor API?
A `GroupDocs.Editor API` é uma API de edição de documentos que permite que desenvolvedores carreguem, modifiquem e salvem programaticamente uma ampla variedade de tipos de arquivo sem exigir Microsoft Office ou Adobe Acrobat. Ela lida com a conversão de documentos, preserva o layout e suporta recursos avançados como campos de formulário e criptografia, tudo através de um modelo de objeto único e consistente.

## Por que escolher a GroupDocs.Editor API?
GroupDocs.Editor processa **documentos de 500 páginas em menos de 5 segundos** em hardware de servidor padrão e suporta **mais de 40** formatos de arquivo — incluindo arquivos clássicos do Office, PDFs, XML, texto simples e formatos delimitados. A API elimina a necessidade de softwares de terceiros caros, oferece segurança integrada (proteção por senha, criptografia e controle de permissões) e funciona de forma consistente em Windows, Linux e macOS, garantindo que você possa oferecer uma experiência de edição confiável para qualquer base de usuários.

## Quem pode se beneficiar?
A GroupDocs.Editor API é valiosa para desenvolvedores de CMS que criam editores dentro da aplicação, engenheiros de automação que precisam de geração de documentos em lote, equipes corporativas que exigem processamento seguro no servidor, provedores SaaS que oferecem edição colaborativa e soluções de relatórios que geram ou modificam PDFs, planilhas e apresentações em tempo real.
