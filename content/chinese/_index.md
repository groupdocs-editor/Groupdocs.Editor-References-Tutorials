# GroupDocs.Editor API – .NET 与 Java 文档编辑

欢迎来到全面的 **GroupDocs.Editor API** 文档和教程中心！无论您是经验丰富的开发者还是刚入门，这个集中资源为您提供将高保真文档编辑、转换和处理集成到 .NET 和 Java 应用程序所需的一切。GroupDocs.Editor API 让您无需 Microsoft Office 或 Adobe Acrobat 即可加载、编辑和保存文档，非常适合云优先和本地部署的解决方案。

## 快速答案
- **GroupDocs.Editor API 的作用是什么？** 它加载文档，将其转换为可编辑的 HTML，允许您修改内容，并在保留布局的同时保存回原始格式。  
- **支持哪些平台？** Windows、Linux 和 macOS，适用于 .NET 6+ 和 Java 8+。  
- **是否需要安装 Office？** 不需要任何外部的 Office 或 Acrobat 安装。  
- **支持多少文件格式？** 超过 40 种输入和输出格式，包括 DOCX、XLSX、PPTX、PDF、HTML、XML、TXT 和 CSV。  
- **API 是否安全？** 是的——它开箱即提供密码保护、加密和细粒度的权限管理。  

## 什么是 GroupDocs.Editor API？
`GroupDocs.Editor API` 是一个文档编辑 API，允许开发者以编程方式加载、修改和保存各种文件类型，无需 Microsoft Office 或 Adobe Acrobat。它处理文档转换，保留布局，并支持表单字段和加密等高级功能，全部通过统一且一致的对象模型实现。

## 为什么选择 GroupDocs.Editor API？
GroupDocs.Editor 在标准服务器硬件上能够在 **5 秒以内处理 500 页文档**，并支持 **40+** 种文件格式——包括经典 Office 文件、PDF、XML、纯文本和分隔格式。该 API 消除了昂贵的第三方软件需求，提供内置安全（密码保护、加密和权限控制），并在 Windows、Linux 和 macOS 上保持一致的工作表现，确保您能够为任何用户群体提供可靠的编辑体验。

## 谁能受益？
GroupDocs.Editor API 对于构建应用内编辑器的 CMS 开发者、需要批量文档生成的自动化工程师、需要安全服务器端处理的企业团队、提供协作编辑的 SaaS 提供商，以及实时生成或修改 PDF、电子表格和演示文稿的报表解决方案都具有价值。
