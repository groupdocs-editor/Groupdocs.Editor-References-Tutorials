## 常见问题

**Q:** *我可以从已签名的 PDF 中读取 form values Java 吗？*  
**A:** 是的。使用 GroupDocs.Editor 加载已签名的 PDF 后，仍然可以调用表单字段 API 检索值，只要签名未加密表单数据。

**Q:** *如何为下拉列表设置 form value Java？*  
**A:** `setValue` 是表单字段对象的方法，用于为字段分配新值。对特定字段对象调用 `setValue` 方法，并传入与下拉项之一匹配的确切选项文本。

**Q:** *有没有办法批量清除 form fields Java？*  
**A:** 当然。`FormFieldCollection` 代表文档中所有表单字段的集合。遍历 `FormFieldCollection` 并对每个字段调用 `clear()`（`clear()` 会移除表单字段的当前值），或者使用 `clearAll()` 辅助方法（如果您使用的版本提供 `clearAll()`，它会一次性清除所有字段）。

**Q:** *GroupDocs.Editor 是否支持加载 Word 文档 Java 并转换为保留表单字段的 PDF？*  
**A:** 是的。使用编辑器加载 DOCX，进行必要的字段调整，然后将文档保存为 PDF——所有表单交互性保持完整。

**Q:** *如果加载后表单字段未被识别，我该怎么办？*  
**A:** 运行上面链接的“修复无效表单字段”教程；API 将尝试修复或重新创建缺失的字段定义。
