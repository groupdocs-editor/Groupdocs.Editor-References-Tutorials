# GroupDocs.Editor API – .NET 與 Java 的文件編輯

歡迎來到全面的 **GroupDocs.Editor API** 文件與教學中心！無論您是資深開發者還是剛起步，本資源提供您整合高保真文件編輯、轉換與處理至 .NET 與 Java 應用程式所需的一切。GroupDocs.Editor API 讓您在不需要 Microsoft Office 或 Adobe Acrobat 的情況下載入、編輯與儲存文件，非常適合雲端優先與本地部署的解決方案。

## 快速解答
- **GroupDocs.Editor API 的功能是什麼？** 它會載入文件，轉換為可編輯的 HTML，讓您修改內容，並在保留版面配置的同時儲存回原始格式。  
- **支援哪些平台？** Windows、Linux 與 macOS，適用於 .NET 6+ 與 Java 8+。  
- **需要安裝 Office 嗎？** 不需要任何外部的 Office 或 Acrobat 安裝。  
- **支援多少種檔案格式？** 超過 40 種輸入與輸出格式，包括 DOCX、XLSX、PPTX、PDF、HTML、XML、TXT 與 CSV。  
- **API 是否安全？** 是的——它內建密碼保護、加密與細緻的權限管理。  

## GroupDocs.Editor API 是什麼？
**GroupDocs.Editor API** 是一套文件編輯 API，讓開發者以程式方式載入、修改與儲存各種檔案類型，且不需要 Microsoft Office 或 Adobe Acrobat。它處理文件轉換、保留版面配置，並支援表單欄位與加密等進階功能，全部透過單一且一致的物件模型。

## 為何選擇 GroupDocs.Editor API？
GroupDocs.Editor 能在標準伺服器硬體上於 5 秒內處理 500 頁文件，且支援 **40+** 種檔案格式——包括傳統 Office 檔、PDF、XML、純文字與分隔格式。此 API 免除昂貴第三方軟體的需求，內建安全功能（密碼保護、加密與權限控制），且在 Windows、Linux 與 macOS 上表現一致，確保您能為任何使用者提供可靠的編輯體驗。

## 誰能受惠？
GroupDocs.Editor API 對於開發 CMS 內嵌編輯器的開發者、需要批次文件產生的自動化工程師、需要安全伺服器端處理的企業團隊、提供協同編輯的 SaaS 供應商，以及即時產生或修改 PDF、試算表與簡報的報表解決方案皆相當有價值。
