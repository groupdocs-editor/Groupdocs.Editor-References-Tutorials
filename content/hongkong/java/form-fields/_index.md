## 常見問題

**Q:** *我可以從已簽署的 PDF 中讀取 form values Java 嗎？*  
**A:** 可以。使用 GroupDocs.Editor 載入已簽署的 PDF 後，仍可呼叫表單欄位 API 取得值，前提是簽章未加密表單資料。

**Q:** *如何為下拉式清單設定 form value Java？*  
**A:** `setValue` 是表單欄位物件的方法，用於為欄位指派新值。於特定欄位物件上呼叫 `setValue` 方法，並傳入與下拉項目之一相符的選項文字。

**Q:** *有沒有辦法批次清除 form fields Java？*  
**A:** 絕對可以。`FormFieldCollection` 代表文件中所有表單欄位的集合。遍歷 `FormFieldCollection`，對每個欄位呼叫 `clear()`（`clear()` 會移除表單欄位的當前值），或在您使用的版本支援時使用 `clearAll()` 輔助方法（`clearAll()` 會一次清除所有欄位）。

**Q:** *GroupDocs.Editor 是否支援載入 Word document Java 並轉換為保留表單欄位的 PDF？*  
**A:** 可以。使用編輯器載入 DOCX，進行必要的欄位調整後，再將文件儲存為 PDF——所有表單互動性皆會保留。

**Q:** *如果載入後表單欄位未被識別，我該怎麼辦？*  
**A:** 執行上方連結的「修復無效表單欄位」教學；API 會嘗試修復或重新建立缺失的欄位定義。
