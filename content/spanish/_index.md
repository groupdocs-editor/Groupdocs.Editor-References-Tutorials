# GroupDocs.Editor API – Edición de documentos para .NET y Java

¡Bienvenido al completo hub de documentación y tutoriales de **GroupDocs.Editor API**! Ya seas un desarrollador experimentado o estés comenzando, este recurso central te brinda todo lo que necesitas para integrar edición de documentos de alta fidelidad, conversión y procesamiento en tus aplicaciones .NET y Java. La GroupDocs.Editor API te permite cargar, editar y guardar documentos sin Microsoft Office ni Adobe Acrobat, lo que la hace ideal para soluciones cloud‑first y on‑premise.

## Respuestas rápidas
- **¿Qué hace GroupDocs.Editor API?** Carga documentos, los convierte a HTML editable, permite modificar el contenido y los guarda nuevamente en el formato original preservando el diseño.  
- **¿Qué plataformas son compatibles?** Windows, Linux y macOS para .NET 6+ y Java 8+.  
- **¿Necesito Office instalado?** No se requieren instalaciones externas de Office o Acrobat.  
- **¿Cuántos formatos de archivo se cubren?** Más de 40 formatos de entrada y salida, incluidos DOCX, XLSX, PPTX, PDF, HTML, XML, TXT y CSV.  
- **¿Es segura la API?** Sí: ofrece protección con contraseña, cifrado y gestión granular de permisos de forma nativa.

## Qué es GroupDocs.Editor API?
El `GroupDocs.Editor API` es una API de edición de documentos que permite a los desarrolladores cargar, modificar y guardar programáticamente una amplia gama de tipos de archivo sin requerir Microsoft Office ni Adobe Acrobat. Gestiona la conversión de documentos, preserva el diseño y admite funciones avanzadas como campos de formulario y cifrado, todo a través de un modelo de objetos único y coherente.

## Por qué elegir GroupDocs.Editor API?
GroupDocs.Editor procesa **documentos de 500 páginas en menos de 5 segundos** en hardware de servidor estándar y admite **más de 40** formatos de archivo, incluidos los clásicos de Office, PDFs, XML, texto plano y formatos delimitados. La API elimina la necesidad de costoso software de terceros, ofrece seguridad incorporada (protección con contraseña, cifrado y control de permisos) y funciona de manera consistente en Windows, Linux y macOS, garantizando que puedas ofrecer una experiencia de edición fiable a cualquier base de usuarios.

## Quién puede beneficiarse?
GroupDocs.Editor API es valiosa para desarrolladores de CMS que crean editores dentro de la aplicación, ingenieros de automatización que necesitan generación masiva de documentos, equipos empresariales que requieren procesamiento seguro del lado del servidor, proveedores SaaS que ofrecen edición colaborativa y soluciones de informes que generan o modifican PDFs, hojas de cálculo y presentaciones al instante.
